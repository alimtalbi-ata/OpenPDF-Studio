# OpenPDF Studio V23.8 — Guide de l’inspecteur

Auteur : Abdelhalim Talbi

Dans le rapport HTML, choisir une catégorie dans **Inspecteur des différences** pour filtrer les constats. Utiliser **Constat précédent/suivant**, ou les flèches haut/bas lorsque le focus est dans l’inspecteur ou le tableau. **Isoler le constat sélectionné** atténue les autres lignes sans les supprimer des exports ou de la navigation.

Les filtres existants de gravité et de recherche se combinent au filtre de catégorie. Une sélection devenue invisible est effacée automatiquement. Les liens d’aperçu ne sont activés que s’ils existent dans le rapport.

Les captures de recette sont issues de Chromium sous Linux, pas de Windows. Cette archive contient un module de diagnostic, pas un exécutable Windows natif.
