# OpenPDF Studio V40.5 — Ergonomie clavier
Auteur : Abdelhalim Talbi

## Nouveautés
- F6 : aller au champ de destination sans parcourir le formulaire.
- Ctrl+L : aller au champ de destination (raccourci conservé).
- Ctrl+Maj+O : ouvrir la sélection du fichier de sortie.
- Suppr dans la liste des PDF : retirer les documents sélectionnés.
- Ctrl+Entrée : lancer l'opération (raccourci conservé).
- Le comportement en cours de traitement interdit les actions concurrentes via les raccourcis.

## Qualification
Contrats de raccourcis et analyse syntaxique Python intégrés à la CI Windows.
Une compilation réussie n'est pas une validation manuelle de l'accessibilité, des lecteurs d'écran ou du DPI.
Les manuels Word/PDF historiques inclus dans l'archive ne sont pas présentés comme actualisés pour V40.5.
