# OpenPDF Studio V24.8 — Guide utilisateur
Auteur : Abdelhalim Talbi

Dans le diagnostic HTML, activez « Afficher les régions vérifiées ». Les raccourcis **Alt+Maj+S** et **Alt+Maj+C** parcourent indépendamment les régions vérifiées des pages source et cible actives. **Échap** efface la sélection. Les raccourcis ne s’activent pas pendant la saisie dans un champ, une liste ou une zone éditable, et n’interfèrent pas avec Ctrl/Meta. Les commandes indisponibles ne sélectionnent rien. Les pages candidates ou non appariées n’établissent jamais d’identité géométrique entre documents.

Qualification navigateur : Chromium Linux headless avec PDF de recette synthétiques ; pas de qualification Windows native. Le projet est un module de diagnostic, pas une application Windows installable complète.
