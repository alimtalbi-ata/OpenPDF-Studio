# OpenPDF Studio V24.4 — Guide de navigation des preuves

Auteur : Abdelhalim Talbi

1. Ouvrir le tableau de bord de diagnostic généré avec deux PDF.
2. Naviguer entre les paires et afficher les régions vérifiées.
3. Utiliser Source ou Cible pour parcourir les régions du document correspondant.
4. Lire le nouveau statut de preuve : document, page, index, rectangle PDF en points et provenance.
5. Effacer la sélection pour remettre le statut à zéro.

Une région n’est affichée que si ses coordonnées ont été validées par le moteur de conversion raster/PDF. Aucune identité source/cible ni attribution sémantique ne sont déduites. Les captures sont réalisées sur Chromium Linux headless, pas sur Windows. Cette livraison est un add-on de diagnostic et non une application Windows native.
