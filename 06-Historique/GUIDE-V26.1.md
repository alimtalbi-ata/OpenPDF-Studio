# OpenPDF Studio V26.1 — Guide Windows

Auteur : Abdelhalim Talbi.

Installer les dépendances de `requirements-windows-v260.txt` puis double-cliquer `LANCER-OPENPDF-STUDIO.cmd`.

**Nouveautés** : sélectionner un PDF et cliquer **Aperçu / pages** pour naviguer entre les pages. Pour une fusion, sélectionner une ligne puis **Monter / Descendre** pour changer l’ordre des documents. Le moteur `edit_pages` permet la réorganisation, la suppression et la rotation des pages par API Python ; son édition interactive reste à intégrer dans la fenêtre.

La prévisualisation fonctionne localement, sans téléversement. Windows non testé nativement dans cet environnement Linux. Les captures précédentes ne constituent pas des captures de la V26.1 Windows.
