# OpenPDF Studio V25.0 — Guide utilisateur

Auteur : Abdelhalim Talbi

Le panneau « État de correspondance des pages » décrit la preuve pour chaque paire active : exacte textuelle, candidate, source non appariée ou cible non appariée. Les régions restent indépendantes. Utilisez Alt+Maj+Flèches pour naviguer, Alt+Maj+S/C pour les régions, Échap pour effacer. Aucun raccourci ne s’applique dans un champ de saisie.

Recette visuelle : Chromium Linux headless, pas Windows natif. Ce livrable est un module de diagnostic, pas une application PDF Windows complète.
