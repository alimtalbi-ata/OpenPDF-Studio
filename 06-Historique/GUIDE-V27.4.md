# OpenPDF Studio V27.4 — Guide Windows
Auteur : Abdelhalim Talbi.

## Exécution
Sur Windows, lancer `BUILD-WINDOWS-INSTALLER.cmd` pour produire l’installateur (connexion Internet et winget nécessaires sur le poste de compilation). Installer ensuite `installer\OpenPDF-Studio-V27.4-Setup.exe`.

## Utilisation
Ajouter des documents PDF, utiliser Fusionner, Compresser ou Découper. Une seule barre d’avancement présente la tâche active. Annuler demande l’arrêt coopératif du traitement. Il faut attendre sa fin avant de fermer l’application.

## Qualification
Tests de cycle de vie réalisés sur Linux. Construction Windows, installation et captures réelles non qualifiées.
