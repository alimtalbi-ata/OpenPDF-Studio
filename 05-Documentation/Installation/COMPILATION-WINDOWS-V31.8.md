# Compilation Windows V31.8

Depuis `02-Compilation/COMPILER-PORTABLE.cmd` ou `COMPILER-INSTALLATEUR.cmd`, les lanceurs exécutent `03-Sources/BUILD-WINDOWS-INSTALLER.cmd` dans le dossier source. Une connexion réseau peut être requise. Les binaires sont produits dans `03-Sources/portable`, `dist` et `installer`. Ne pas considérer un EXE comme qualifié sans tests Windows réels.
