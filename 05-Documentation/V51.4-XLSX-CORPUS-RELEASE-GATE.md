# OpenPDF Studio V51.4 — Corpus de qualification PDF → Excel (V519)

**Auteur : Abdelhalim Talbi** · 24 octobre 2026 · fonctionnalité de qualification source, non embarquée dans l'exécutable Windows.

## Objet

Le comparateur V517 mesure un PDF à la fois contre une annotation indépendante. V519 agrège un corpus **de deux à 64 cas**, calcule les taux micro-pondérés à partir des nombres de cellules et de tableaux (et non la moyenne des pourcentages), et bloque la validation si les seuils définis ne sont pas atteints. Un corpus purement synthétique ne peut pas être présenté comme qualifié humainement : le rapport indique séparément `human_reviewed_cases` et `synthetic_cases` et le seuil `min_human_reviewed` est explicite.

## Contrat du manifeste

Le manifeste UTF-8 doit se trouver dans le répertoire racine des fichiers. Les chemins des trois artefacts de chaque cas sont relatifs à ce répertoire ; les liens symboliques et les sorties hors racine sont refusés. Chaque annotation individuelle utilise le schéma `openpdf.xlsx.ground_truth.v1`, porte le SHA-256 du PDF et a été produite indépendamment du convertisseur.

```json
{
  "schema": "openpdf.xlsx.corpus.v1",
  "thresholds": {
    "min_nonempty_cell_accuracy": 0.98,
    "min_table_recall": 0.95,
    "min_merge_recall": 0.95,
    "max_extra_nonempty_cells": 0,
    "min_human_reviewed": 2
  },
  "cases": [
    {"id": "document-a", "pdf": "a.pdf", "xlsx": "a.xlsx", "annotations": "a.json"},
    {"id": "document-b", "pdf": "b.pdf", "xlsx": "b.xlsx", "annotations": "b.json"}
  ]
}
```

Exécution depuis la racine du dépôt :

```powershell
python 03-Sources/openpdf_xlsx_corpus_gate_v519.py --manifest corpus/corpus.json --report corpus/qualification.json
```

Code retour `0` : seuils respectés ; `3` : seuils non respectés ; `2` : entrée, fichier, preuve ou destination invalide. Le rapport ne contient ni texte des cellules ni chemins ni identifiants des cas ; uniquement compteurs, métriques, seuils et empreintes SHA-256. Le rapport existant n'est jamais écrasé.

## Critères et limites

- Exactitude des cellules non vides = somme des cellules exactes / somme des cellules non vides annotées.
- Rappel des tableaux = somme des tableaux correspondants / somme des tableaux attendus.
- Rappel des fusions = somme des fusions correspondantes / somme des fusions attendues.
- Cellules supplémentaires = somme des cellules non vides en excès, plafonnée par le seuil.
- Le seuil de relecture humaine doit être strictement supérieur à zéro pour toute campagne de qualification métier ; `0` est acceptable uniquement pour la CI synthétique.
- Un taux à 100 % sur un corpus synthétique n'est pas une mesure de fidélité documentaire générale. Les positions, styles, tableaux sans bordures, images et fidélité visuelle restent **non évalués**.

## Sécurité et exploitation

Le traitement rejette les manifestes surdimensionnés, les clés JSON dupliquées, les seuils booléens/NaN/Inf, les identifiants dupliqués, les chemins absolus/traversal, les symlinks intermédiaires, les cas dupliqués et les rapports individuels incomplets. Les PDF/XLSX et annotations sont contrôlés par l'oracle V517 et le précontrôle OOXML V515/V516.

Les tests V519 incluent des scénarios adversariaux, un calcul micro-pondéré et une conversion réelle de deux PDF synthétiques en XLSX en CI Ubuntu/Windows. Aucune capture d'écran Windows, signature Authenticode ni qualification humaine n'est revendiquée par ce module.
