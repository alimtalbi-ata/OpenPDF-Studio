# V25.4 — Audit SHA-256 vérifiable
Auteur : Abdelhalim Talbi

- Export JSON d'un journal de régions vérifiées avec chaînage SHA-256 et empreinte finale.
- Vérificateur Python indépendant avec contrôles de structure, de provenance, de géométrie et de séquence.
- Tests d'altération d'une coordonnée, suppression d'entrée et altération de l'empreinte finale.
- Recette Chromium Linux sur PDF synthétiques et capture réelle de l'interface.
- Aucune signature numérique ni certification de fidélité documentaire revendiquée.
