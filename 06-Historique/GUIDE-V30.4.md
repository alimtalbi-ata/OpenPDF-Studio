# OpenPDF Studio V30.4 — Guide utilisateur
Auteur : Abdelhalim Talbi

## Espace de travail
Appuyez sur **F6** ou choisissez **Espace de travail** dans la barre de menus. Les actions sont regroupées en **Organiser les PDF** (fusion, extraction, compression) et **Convertir et exporter** (Word, Excel, PowerPoint, TXT). Cliquez sur une action, sélectionnez les fichiers demandés puis confirmez. **Échap** ferme l’espace.

Les actions historiques restent disponibles ; la nouvelle fenêtre constitue un point d'entrée unifié. Les conversions de texte éditable ne préservent pas nécessairement la mise en page.

## Construire sous Windows
Extraire le ZIP puis lancer `BUILD-WINDOWS-INSTALLER.cmd`. Les scripts nécessitent un accès aux dépendances (Python 3.12, pip, PyInstaller et Inno Setup). Les exécutables ne sont pas inclus dans les sources.
