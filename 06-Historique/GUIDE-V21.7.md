# OpenPDF Studio V21.7 — Régions géométriques vérifiées

Auteur : Abdelhalim Talbi.

Dans le rapport HTML, cochez **Afficher les régions vérifiées** pour superposer les cadres bleus aux aperçus. Les cadres ne sont créés que pour les régions raster validées par la chaîne V21.4, sur des pages PDF effectivement ouvertes et dont les dimensions sont vérifiées. Les pages recadrées ou tournées sont exclues. Limite : 30 cadres par page.

Cette fonction ne convertit pas automatiquement les zones de différence calculées dans le navigateur et ne prouve pas la nature d'un changement. Le rapport reste un module de diagnostic, non une application Windows autonome. Les captures réelles et les tests natifs Windows ne sont pas disponibles.
