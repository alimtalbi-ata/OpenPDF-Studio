# OpenPDF Studio V20.6 — Recalage manuel de superposition

Auteur : Abdelhalim Talbi.

1. Produire le diagnostic HTML avec deux PDF et ouvrir le rapport dans un navigateur.
2. Sélectionner une paire de pages, puis activer « Superposition ».
3. Ajuster « Opacité cible » et les curseurs de décalage horizontal et vertical (-150 à +150 pixels).
4. Cliquer sur « Réinitialiser le recalage » pour revenir à 0/0.
5. Vérifier visuellement : ce recalage est manuel, local à la superposition, non enregistré dans le PDF.

**Limites** : aucune estimation automatique de transformation, pas de recalage par homographie ou changement d'échelle ; les différences de taille et de rendu restent susceptibles de fausser la comparaison. Aucun test Windows natif ni capture réelle de l'application complète.
