# OpenPDF Studio V21.6 — Navigation des corrélations
Auteur : Abdelhalim Talbi

Depuis « Corrélation texte / régions visuelles », utiliser les boutons de page pour afficher le véritable aperçu PDF correspondant. Le bouton active la paire et déplace le focus clavier sur le volet concerné. Si la page n’est pas présente, un message explicite est affiché ; aucune correspondance n’est inventée.

**Limites** : navigation disponible uniquement si une corrélation spatiale vérifiable et un aperçu apparié existent. La boîte PDF de la région n’est pas automatiquement dessinée dans le navigateur. L’IoU ne prouve pas une modification sémantique. Pas de recette Windows native ni de captures réelles.
