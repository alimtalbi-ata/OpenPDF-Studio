# OpenPDF Studio V22.8 — Guide utilisateur

Auteur : Abdelhalim Talbi

## Graphiques descriptifs

Ouvrir le rapport HTML de diagnostic, puis la section **Synthèse globale du diagnostic**. Sélectionner une gravité ou une catégorie pour filtrer les deux graphiques. Le bouton **Réinitialiser** restaure tous les comptages. Les barres utilisent des éléments HTML `meter` accessibles et ne nécessitent pas de service externe.

Les filtres de synthèse sont indépendants de ceux du tableau des anomalies. L'export JSON global V22.7 conserve toutes les anomalies ; il n'est **pas** filtré par les nouveaux graphiques. Aucune certification de fidélité n'est déduite des comptages.

## Limites de validation

Recette visuelle réelle en navigateur, captures d'écran réelles et tests natifs Windows non réalisés dans cet environnement. Le ZIP est un add-on de diagnostic, pas une application Windows complète. Voir CAPTURES-STATUS.md.
