# OpenPDF Studio V31.4 — Guide rapide

Auteur : Abdelhalim Talbi.

## Accueil
Quatre actions prioritaires, avec leurs étapes visibles : **Fusionner**, **Compresser**, **Découper**, **Vers Word**. Cliquer sur une action ouvre le parcours existant de sélection, paramètres utiles et destination. Les traitements restent asynchrones.

- **Fusionner** : choisir plusieurs PDF, puis le PDF résultat.
- **Compresser** : choisir le PDF, puis le fichier optimisé. Le gain dépend du contenu.
- **Découper** : choisir le PDF, les pages de début et de fin, puis la destination.
- **Vers Word** : choisir un PDF et un DOCX ; l'export est principalement textuel, pas une reconstruction fidèle des mises en page complexes.

Raccourcis : Ctrl+Maj+M/C/D/W. Les fonctions avancées restent dans les menus.

## Windows
Extraire le ZIP, lancer `BUILD-WINDOWS-INSTALLER.cmd` pour générer l'application et l'installateur. PyInstaller et Inno Setup requis selon le script. La compilation n'a pas été effectuée sous Windows dans cet environnement.
