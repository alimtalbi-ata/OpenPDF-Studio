# OpenPDF Studio V31.1 — Guide rapide

Auteur : Abdelhalim Talbi.

## Actions courantes

1. **Fusionner** : assembler plusieurs PDF.
2. **Compresser** : réduire la taille d’un PDF.
3. **Découper** : extraire des pages.
4. **Vers Word** : sélectionner un PDF puis choisir une destination DOCX et exécuter.

Les quatre actions sont accessibles directement en haut de l’interface. Le bouton Word prépare la conversion dans le formulaire existant ; il ne lance pas automatiquement la conversion.

## Construction Windows

Exécuter `BUILD-WINDOWS-INSTALLER.cmd` sous Windows. Les binaires Windows et les captures natives doivent être qualifiés sur Windows.
