# OpenPDF Studio V23.3 — Recette multipage
Auteur : Abdelhalim Talbi

## Exécution
`python browser_pdf_v233.py` : génère deux PDF de trois pages (textes, cadres, sections), lance Chromium Linux headless, vérifie navigation avant/arrière, zoom, filtres, export CSV et JSON, et enregistre les preuves dans `captures-v23.3/`.

Les documents sont synthétiques ; les anomalies sont des fixtures de test. Une capture Chromium Linux n'est pas une capture Windows. Aucun test natif Windows ni parcours d'édition PDF n'est couvert.
