# OpenPDF Studio V24.9 — Guide utilisateur

Auteur : Abdelhalim Talbi

Dans le diagnostic HTML, utilisez **Alt+Maj+Flèche gauche** et **Alt+Maj+Flèche droite** pour changer de page. Les raccourcis sont inactifs dans les champs de saisie. Le statut de navigation indique explicitement si la page est appariée par correspondance textuelle, candidate ou non appariée. Aucune correspondance géométrique entre régions n’est déduite.

Qualification navigateur : Chromium Linux headless, non Windows natif.
