# V51.4 — Mesure indépendante de fidélité PDF → Excel (V517)

**Auteur : Abdelhalim Talbi** · 24 octobre 2026 · outil de qualification, non embarqué dans le portable Windows.

## Pourquoi

L'audit V515 prouve que le classeur reproduit exactement **l'extraction PyMuPDF** ; il ne prouve pas que PyMuPDF a correctement identifié les tableaux métier. Le nouveau contrôle compare le classeur à une vérité terrain indépendante, créée **manuellement** ou déterminée **avant** la génération d'un PDF synthétique. Les cellules attendues ne sont jamais dérivées de \`find_tables()\`.

## Exécution

\`\`\`powershell
python 03-Sources/openpdf_xlsx_ground_truth_v517.py --pdf source.pdf --xlsx resultat.xlsx --annotations truth.json --report metrics.json
\`\`\`

Le rapport contient uniquement des métriques, des empreintes SHA-256 et la provenance de l'annotation. Les textes des cellules ne sont pas copiés dans le rapport.

- **Code retour 0 :** correspondance exacte, pas de tableau/cellule supplémentaire.
- **Code retour 3 :** écarts mesurés, à investiguer.
- **Code retour 2 :** entrée invalide, archive hostile, rapport déjà existant ou erreur.

## Schéma d'annotation V1

\`\`\`json
{
  "schema": "openpdf.xlsx.ground_truth.v1",
  "source_sha256": "<64 hex characters of PDF SHA-256>",
  "origin": "human_reviewed",
  "tables": [
    {
      "page": 1,
      "index": 1,
      "cells": [["Volume", "Capacite"], ["SAN-A", "20 To"]],
      "merges": []
    }
  ]
}
\`\`\`

Les indices de tableau sont locaux à chaque page. Les fusions sont \`[row_start, column_start, row_end, column_end]\` en indices 1-based relatifs à la grille, et les cellules couvertes doivent être nulles. Les annotations doivent être validées indépendamment de la sortie XLSX.

## Métriques et interprétation

- **table_precision/recall** : tables correspondantes selon page/index ; ce n'est pas un appariement géométrique optimal.
- **cell_exact_accuracy** : cellules identiques, y compris vides, divisées par les cellules annotées.
- **nonempty_cell_accuracy** : fidélité des cellules contenant des données.
- **cell_normalized_accuracy** : variante séparée NFKC/espaces, ne remplace jamais l'exactitude.
- **merge_precision/recall** : fusions attendues et retrouvées.
- **extra_nonempty_cells** : contenu en trop, y compris tableaux supplémentaires.
- **visual_fidelity = not_assessed** : pas de preuve visuelle, de styles, de dimensions ou de rendu.

Les annotations sont liées à l'empreinte SHA-256 du PDF. Le contrôle refuse les doublons JSON, grilles irrégulières, fusions chevauchantes, liens symboliques et classeurs avec formules/hyperliens actifs. Le précontrôle OOXML de production V515/V516 est réutilisé avant ouverture.

## Qualification et limites

15 tests automatisés incluent une vraie conversion de PDF synthétique avec valeurs attendues connues à la génération, mutations de cellules, tables manquantes/supplémentaires, fusions, protection anti-formule, confidentialité du rapport et CLI. Le corpus ne constitue **pas** encore une qualification de documents clients ou de l'interface Windows.

Les tests Linux locaux utilisent le candidat source V51.4 plus un **adaptateur local limité** pour l'audit OOXML absent du ZIP candidat; seule la CI GitHub du dépôt complet vérifie l'intégration avec le vrai contrôle V515/V516. Aucun test Windows natif ni installateur de ce nouveau commit n'est revendiqué avant résultat CI.
