# OpenPDF Studio V30.2 — Guide utilisateur
Auteur : Abdelhalim Talbi

## Navigation simplifiée
La barre d’actions rapides donne accès à **Fusionner**, **Découper** et **Compresser**. Le menu **Actions rapides** permet également de sélectionner les conversions Word, Excel, PowerPoint et texte. Les raccourcis clavier sont affichés dans ce menu.

Pour convertir, sélectionnez l’action, ajoutez un PDF, indiquez le fichier de sortie puis cliquez sur **Exécuter**. Les exports bureautiques produisent du texte éditable ; ils ne garantissent pas la fidélité visuelle ni la reconstruction des tableaux.

## Windows
Exécuter `BUILD-WINDOWS-INSTALLER.cmd` sur Windows x64. Ce script construit les exécutables et l’installateur, sous réserve de disponibilité des dépendances. La compilation Windows réelle reste à qualifier.
