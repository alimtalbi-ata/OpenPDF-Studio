# Guide OpenPDF Studio V29.1

Sous Windows, exécuter `BUILD-WINDOWS-INSTALLER.cmd` pour générer l’EXE et le Setup. Puis `QUALIFY-WINDOWS-V29.1.cmd` pour contrôler la fenêtre de l’application. Sur une VM Windows **jetable, vierge de toute installation OpenPDF Studio**, `QUALIFY-INSTALLER-V29.1.cmd` teste l’installation et la désinstallation. Lancer ce dernier script modifie réellement la machine de test. Lire le rapport `qualification-install-v29.1.json`.

Les captures Windows ne sont pas produites depuis Linux. Auteur : Abdelhalim Talbi.
