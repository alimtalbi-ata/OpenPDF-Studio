# OpenPDF Studio V27.3 — Guide utilisateur
Auteur : Abdelhalim Talbi.

Lancer `openpdf_windows_v273.py` avec les dépendances installées, ou compiler sous Windows via `BUILD-WINDOWS-INSTALLER.cmd`. Les commandes Fusionner, Compresser et Découper lancent une tâche indépendante. La barre inférieure indique une progression d’étapes (non proportionnelle au temps restant). **Annuler** demande l’arrêt au prochain point de contrôle ; une opération de sauvegarde en cours peut prendre du temps avant de s’interrompre. Les fichiers sources ne sont jamais écrasés.

L’installateur Windows n’a pas été compilé dans cet environnement Linux.
