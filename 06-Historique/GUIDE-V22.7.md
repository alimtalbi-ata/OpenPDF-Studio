# OpenPDF Studio V22.7 — Synthèse globale

Ouvrir le rapport HTML généré et consulter « Synthèse globale du diagnostic ». Les répartitions par gravité, catégorie et document/page sont établies à partir des anomalies présentes dans le rapport. Le bouton « Exporter la synthèse JSON » télécharge les mêmes compteurs. La synthèse est descriptive et ne certifie pas la fidélité des documents.

Captures : aucune capture native Windows réalisée. Auteur : Abdelhalim Talbi.
