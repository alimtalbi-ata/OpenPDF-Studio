# OpenPDF Studio V26.2 — Guide utilisateur Windows
Auteur : Abdelhalim Talbi

## Démarrage
Installer les dépendances décrites dans `requirements-windows-v260.txt`, puis lancer `LANCER-OPENPDF-STUDIO.cmd`.

## Édition des pages
1. Ajouter un PDF, sélectionner son nom dans la liste.
2. Cliquer sur **Aperçu / pages**.
3. Sélectionner une ou plusieurs pages avec Ctrl ou Maj.
4. Utiliser **Monter**, **Descendre**, **Rotation +90°**, **Rotation -90°** ou **Supprimer**.
5. Cliquer sur **Enregistrer sous…** pour créer un nouveau PDF.

Le PDF original n'est pas modifié, sauf si vous choisissez explicitement le même chemin comme destination.

## Limites
Les annotations et formulaires complexes peuvent ne pas être conservés lors d'une reconstruction des pages. Les captures historiques sont conservées ; aucune capture native Windows V26.2 n'a été réalisée. Les scripts de construction Windows sont fournis mais aucun exécutable Windows n'est précompilé.
