# OpenPDF Studio V21.5 — Export JSON du diagnostic spatial

Auteur : Abdelhalim Talbi.

Dans le rapport HTML, cliquer sur **Exporter diagnostic JSON** pour enregistrer les régions PDF vérifiées, les corrélations, les rejets et les limites de la méthode. L’export est local et sans réseau. Le champ `sha256_payload` contrôle l’intégrité du JSON canonique hors de ce champ ; il ne prouve ni l’authenticité de l’émetteur ni la fidélité des PDF.

Les anomalies calculées seulement dans le navigateur ne sont **pas** converties automatiquement en coordonnées PDF. Toute corrélation exige une validation humaine. Les captures d’écran natives Windows ne sont pas disponibles : voir CAPTURES-STATUS.md.
