# OpenPDF Studio V30.3 — Guide utilisateur
Auteur : Abdelhalim Talbi

## Actions rapides
Les raccourcis Ctrl+Alt+W/E/P/T ouvrent directement la sélection du PDF puis du document de sortie. Ils ne se limitent plus à changer la sélection d’une liste. Le menu « Convertir directement » fournit les mêmes actions.

## Précautions
Un fichier de sortie existant nécessite confirmation. L’annulation d’un dialogue ne lance aucun traitement. Les exports Office contiennent du texte modifiable mais ne reproduisent pas fidèlement tableaux, graphiques ou mise en page.

## Windows
Lancer `BUILD-WINDOWS-INSTALLER.cmd` depuis le dossier extrait. Python 3.12, PyInstaller et Inno Setup sont nécessaires (le script tente de les installer). Les binaires n'ont pas été construits ni testés sur Windows dans cet environnement.
