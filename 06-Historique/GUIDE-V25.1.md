# OpenPDF Studio V25.1 — Guide utilisateur

Auteur : Abdelhalim Talbi.

## Contrôle multipages
Le bandeau « Pages » affiche séparément la disponibilité de la source et de la cible, ainsi que le nombre de régions géométriques validées par document. Les états exact-text, candidate-text et unmatched restent distincts. Un appariement candidat exige une revue humaine ; une page non appariée n’autorise aucune comparaison géométrique implicite.

## Navigation
Alt + Maj + flèche gauche/droite pour changer de comparaison ; Alt + Maj + S/C pour naviguer entre les régions source/cible ; Échap pour effacer la sélection. Les raccourcis sont ignorés dans les champs de saisie.

## Qualification
Tests Python, JavaScript et navigateur Chromium Linux headless. Les captures sont réelles sous Linux et ne prouvent pas une qualification Windows native. Il s'agit d'un module de diagnostic, pas de l'application Windows complète.
