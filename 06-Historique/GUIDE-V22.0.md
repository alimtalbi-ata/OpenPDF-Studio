# OpenPDF Studio V22.0 — Synchronisation des diagnostics

Auteur : Abdelhalim Talbi.

## Fonctionnement
Dans le rapport HTML, les boutons de corrélation permettent de rejoindre la page concernée. Le panneau « contexte de page » indique le nombre de régions géométriques vérifiées sur cette page et active leur affichage lorsque disponibles. Cliquer sur un rectangle affiche la page et son numéro de région ; le bouton Effacer annule la sélection.

**Important :** la synchronisation est effectuée **au niveau de la page**. Une corrélation textuelle ne désigne pas automatiquement un rectangle précis. Aucune attribution sémantique n'est inférée.

## Validation et limites
Tests unitaires Python et suites JavaScript ; recette visuelle en navigateur et qualification Windows native non réalisées. Les aperçus de PDF ne sont pas des captures réelles de l'interface Windows.
