# Guide V26.3 — Windows

1. Installer Python et les dépendances dans `requirements-windows-v260.txt`.
2. Lancer `LANCER-OPENPDF-STUDIO.cmd`.
3. Ajouter un PDF et cliquer sur **Aperçu / pages**.
4. Cliquer sur une miniature pour la sélectionner. Pour plusieurs pages, utiliser Ctrl/Maj dans la liste à gauche.
5. Glisser une miniature sélectionnée à l’emplacement voulu dans la galerie horizontale. Les commandes Monter/Descendre restent disponibles.
6. Cliquer sur **Enregistrer sous…** pour produire un nouveau PDF.

**Limites** : aperçu chargé au fil de l’affichage ; les PDF très volumineux peuvent ralentir l’interface. Pas de qualification Windows native dans cet environnement.
