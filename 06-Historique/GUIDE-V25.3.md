# OpenPDF Studio V25.3 — Journal des preuves

Dans la navigation des comparaisons, sélectionner des régions vérifiées source ou cible. Le bouton **Exporter le journal des preuves JSON** télécharge les 100 dernières sélections valides, avec numéros de séquence, pages, coordonnées PDF et état d’appariement textuel. **Vider le journal** efface les entrées. Aucun appariement de régions inter-documents n’est affirmé. Les pages non appariées restent identifiées comme telles. Les preuves sont locales et ne sont pas envoyées au réseau.

Les captures Chromium Linux sont réelles ; aucune qualification Windows native n’est revendiquée. Auteur : Abdelhalim Talbi.
