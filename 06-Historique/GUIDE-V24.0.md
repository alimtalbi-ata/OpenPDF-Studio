# OpenPDF Studio V24.0 — Guide utilisateur

Auteur : Abdelhalim Talbi

Dans le tableau de bord de diagnostic, sélectionner un constat puis « Afficher région vérifiée » pour parcourir les rectangles PDF dont les coordonnées et la provenance ont été contrôlées. Le bouton est désactivé si aucune région de la page n’est vérifiée. La navigation entre les régions ne constitue **pas** une association automatique entre une anomalie textuelle et une région.

Recette : `python browser_verified_v240.py` (Chromium Linux), `python -m unittest discover -p "test*.py" -q` et tests JavaScript Node.

Les captures du navigateur sont des captures Linux réelles, et non des captures Windows. Ce paquet est un add-on de diagnostic, pas un exécutable Windows complet.
