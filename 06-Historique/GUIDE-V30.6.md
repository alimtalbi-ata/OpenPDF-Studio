# Guide OpenPDF Studio V30.6

Démarrer l’application via `openpdf_windows_v306.py` (Python) ou compiler sous Windows avec `BUILD-WINDOWS-INSTALLER.cmd`.

- F6 : espace de travail (fusion, extraction, compression, conversions).
- Ctrl+K : recherche rapide.
- Pour une conversion, choisir le PDF et la destination ; confirmer tout remplacement.
- Pour les exports Word, Excel et PowerPoint, les éléments textuels sont éditables, mais la fidélité graphique n’est pas garantie.

Le build Windows exécute les tests V2.x et V3.x avant compilation. Les vrais exécutables et captures Windows restent à qualifier sur Windows.
