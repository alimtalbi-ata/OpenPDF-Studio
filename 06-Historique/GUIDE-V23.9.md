# OpenPDF Studio V23.9 — Navigation vers les régions vérifiées

Dans **Inspecteur des différences**, sélectionner un constat possédant un lien d’aperçu. Le bouton **Afficher région vérifiée** devient disponible uniquement lorsque la page associée contient des régions raster vérifiées et converties en coordonnées PDF. Chaque clic parcourt les régions de cette page et active leur visualisation.

**Important** : le bouton ne prouve pas que la région correspond au constat choisi ; il fournit une navigation contextuelle vers les zones vérifiées de la même page. Aucun rapprochement géométrique implicite, aucune certification de fidélité.

Recette Chromium Linux avec PDF synthétiques, pas de qualification Windows native. Auteur : Abdelhalim Talbi.
