# OpenPDF Studio V22.2 — Fiche de preuves contextualisée

Auteur : Abdelhalim Talbi

Dans le rapport HTML, cochez **Afficher les régions vérifiées**, puis sélectionnez un rectangle. La fiche présente la page, les coordonnées en points PDF, la provenance, le nombre de corrélations géométriques **sur la page** et le résumé de qualité du diagnostic. Le compteur n’établit pas de lien individuel entre le rectangle et une anomalie textuelle. Utilisez **Effacer la sélection** pour remettre la fiche à zéro.

Le rapport fonctionne hors ligne. Les captures réelles de l’application Windows ne sont pas disponibles ; les rendus PDF ne sont pas des captures d’écran. Tests Windows natifs et validation visuelle manuelle encore requis. Ce package est un add-on de diagnostic, pas la suite Windows complète.
