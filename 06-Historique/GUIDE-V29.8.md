# OpenPDF Studio V29.8 — Guide Windows
Auteur : Abdelhalim Talbi.

Exécuter `BUILD-WINDOWS-INSTALLER.cmd` sur Windows pour compiler l’application, l’installateur Inno Setup et la version portable onefile. Le ZIP contient les sources, pas les exécutables compilés. Lancer `QUALIFY-PORTABLE-V29.8.cmd` et `QUALIFY-UI-V29.8.cmd` pour qualifier les binaires sur une VM Windows. Fusion, extraction et compression utilisent un routage par identité de fonction : une extension avec un nom similaire ne peut plus détourner le contrôleur PDF.

Les conversions bureautiques et l'interface complète restent à qualifier sous Windows. Les captures Windows réelles sont absentes de cette livraison.
