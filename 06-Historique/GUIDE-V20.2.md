# OpenPDF Studio V20.2 — Navigation par anomalie

Auteur : Abdelhalim Talbi

Dans le rapport HTML autonome, filtrer par gravité ou saisir une recherche, sélectionner une anomalie dans le menu **Anomalie**, puis cliquer **Afficher l’anomalie**. La ligne correspondante reçoit le focus et, si une page PDF est disponible, la paire de pages est activée. Les anomalies sans aperçu restent consultables dans le tableau. Le menu suit les filtres actifs.

La géométrie n’est pas inférée : les cadres rouges nécessitent des coordonnées explicites. La navigation n'implique aucune validation automatique du document.
