# OpenPDF Studio V30.1 — Guide utilisateur
Auteur : Abdelhalim Talbi

## Installation Windows
Extraire le ZIP puis exécuter `BUILD-WINDOWS-INSTALLER.cmd` sur Windows x64 avec accès Internet pour les dépendances. Le script génère les versions installable et portable ; ces exécutables ne sont pas précompilés dans le ZIP.

## Utilisation
Ajouter un ou plusieurs PDF, sélectionner une opération, choisir la destination, puis lancer le traitement. Les conversions Word/Excel/PowerPoint produisent du texte éditable ; la restitution exacte de la mise en page, des tableaux et des images n'est pas garantie. Ne pas écraser le document source.

## V30.1
Contrôleur de conversion indépendant de Tkinter ; écriture temporaire et remplacement atomique du résultat pour préserver les fichiers existants en cas d'échec ; raccordement des opérations de conversion au lanceur historique.

## Limites
Qualification des EXE, de l'installateur et captures réelles Windows : non effectuées dans l'environnement Linux.
