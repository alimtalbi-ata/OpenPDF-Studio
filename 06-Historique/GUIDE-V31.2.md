# OpenPDF Studio V31.2 — Guide utilisateur
Auteur : Abdelhalim Talbi

## Accès rapide
Quatre actions courantes sont présentées en deux colonnes : **Fusionner**, **Compresser**, **Découper** et **Vers Word**. Sélectionner une action, choisir les fichiers et la destination, puis lancer le traitement. Les options avancées restent accessibles dans les menus existants.

## Raccourcis
- Ctrl+Maj+M : fusionner
- Ctrl+Maj+C : compresser
- Ctrl+Maj+D : découper
- Ctrl+Maj+W : convertir vers Word

Les messages d'aide au survol restaurent le statut précédent, sauf si un traitement l'a modifié entre-temps.

## Windows
Extraire le ZIP, puis exécuter `BUILD-WINDOWS-INSTALLER.cmd` sur Windows. Le script construit le portable et l'installateur. Aucune compilation Windows n'a été effectuée dans cet environnement Linux.
