# OpenPDF Studio V26.4 — Guide Windows
Auteur : Abdelhalim Talbi.

## Lancement
1. Installer Python 3 et les dépendances de `requirements-windows-v260.txt`.
2. Double-cliquer sur `LANCER-OPENPDF-STUDIO.cmd`.
3. Ajouter un PDF, puis ouvrir **Aperçu / pages**.
4. Déplacer les pages par glisser-déposer, sélectionner plusieurs pages, pivoter, supprimer, puis **Enregistrer sous**.
5. Faire défiler horizontalement la galerie et ajuster le zoom de l'aperçu avec les commandes −, 100 %, +.

## Performance
La galerie V26.4 ne rend que les miniatures visibles avec une marge de préchargement ; le cache est borné autour de la zone visible. Le document source reste inchangé jusqu'à Enregistrer sous.

## Qualification
Tests automatisés exécutés sous Linux ; validation Windows native et captures Windows réelles encore requises. Le ZIP contient le code et les scripts de lancement, pas un exécutable Windows précompilé.
